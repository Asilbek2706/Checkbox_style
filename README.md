# ☑️ Custom Styled Checkboxes

This project demonstrates how to create **custom-styled checkboxes** using pure **HTML and CSS**.  
The default browser checkbox is hidden and replaced with a modern, user-friendly design.

---

## 📌 Project Overview

The goal of this project is to practice styling form elements by creating custom checkboxes without using JavaScript.  
Each checkbox reacts to hover and checked states with smooth visual feedback.

---

## ✨ Features

✅ Custom checkbox design  
✅ Default browser checkbox hidden  
✅ Hover effect  
✅ Checkmark icon appears when selected  
✅ Fully built with HTML & CSS  
✅ Beginner-friendly project

## ⚙️ How It Works

- The native checkbox input is hidden using `opacity: 0`
- A `span` element is styled as a custom checkbox
- CSS sibling selectors (`:checked`) control the checked state
- A checkmark is created using the `::after` pseudo-element
